# Qytrix

A dark, purple-accented browser-style start page.

## Features
- Qytrix tab branding and custom SVG favicon
- Browser-style tab strip and address bar
- Search queries open Google results in a new `about:blank` tab
- Direct website addresses open normally in a new tab
- Responsive layout for desktop and mobile

## Deploy
Import this repository into Vercel. The site is a static HTML page; no build command or framework is required. Set the output directory to the repository root.
